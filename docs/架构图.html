门控与拒答向量 0.88 / BM25 6.5 双低即固定拒答，不调模型
流式生成DeepSeek 三回调 → delta；结束补剂量提示 + 免责声明

检索二阶段　RrfFusion：知识命中 + DrugRetriever（t_drug 整表缓存 + BM25，药名加权）→ 统一编号 [1]..[n] 供引用

图上没画、但影响部署的四件事

  • 鉴权边界只有一层：8087 未设 server.address，绕过网关直连即无鉴权待修
  • 状态仍是单机态：待确认风险（Map，每会话 1 条）、验证码、SessionMemory（40 条）都在进程内，多实例会错乱待修
  • 向量库不可横向扩展：InMemory + 全量 JSON 重写，`vector-store: redis` 只有配置项没有实现待修
  • 多轮上下文未生效：记忆只写入与回放，组装 prompt 时只拼 evidence，历史不进 LLM待修
